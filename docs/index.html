DayStream

A fast, native daily-notes stream for your existing markdown vault. Logseq-compatible, plain files, no lock-in.

Download for macOS

One endless stream

All your daily notes in a single scroll, newest first. Click a calendar day to jump anywhere.

Plain markdown

Notes are ordinary .md files in journals/. Works alongside Logseq or any editor.

Outliner tasks

TODO / DOING / DONE markers, nested bullets, cross-note task syncing, and one-click carry-forward to today.

[[Wikilinks]] & pages

Click a wikilink to open (or create) a page, with Logseq-style linked references.

Menu bar quick add

Capture a task for today from the menu bar without switching apps.

Native & fast

SwiftUI + AppKit on macOS 15+. No Electron, no cloud account.

Getting started

  1. Download DayStream-macOS.zip from the releases page and unzip it.
  2. Move DayStream.app to /Applications (or ~/Applications) and open it.
  3. Pick your vault — the folder that contains a journals/ directory (a Logseq vault root works as-is).
  4. That's it. Today's note is created automatically; start typing.

Building from source

git clone https://github.com/SubhadityaMukherjee/daily_stream.git
cd daily_stream
./scripts/build_and_install release   # builds, installs to ~/Applications, launches

Requires Xcode 16+ (macOS 15 SDK). Full details in the README.

Branching & releases

  • develop — active development; CI builds and tests every push.
  • main — stable; releases are tagged from it (v1.0.0, v1.1.0, …) and published as GitHub Releases.
